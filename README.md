# MHT to PDF Book Converter (Linux)

Скрипт автоматизации на Python для конвертации сложных электронных книг из формата `.mht` (`.mhtml`) в полноценный, аккуратно выровненный многостраничный PDF-документ.

## 🚀 Особенности решения
* **Обход ограничений Chromium:** Скрипт автоматически раскрывает внутренние скроллбары (`overflow: scroll`), в которых часто зажаты электронные книги в формате MHT.
* **Борьба с наслоениями текста:** Принудительно сбрасывает абсолютное и фиксированное позиционирование CSS (`position: absolute/fixed`), выстраивая страницы книги друг за другом в нормальный поток документа.
* **Имитация прокрутки (Lazy Loading):** Робот автоматически прокручивает страницу до самого конца перед печатью, чтобы активировать загрузку изображений и динамического текста.
* **Без лишних зависимостей:** Не требует установки `snapd` или сторонних менеджеров драйверов — работает напрямую через системный Chromium.

---

## 🛠 Требования и установка

### 1. Подготовка Chromium в Linux (Ubuntu/Debian)
Поскольку стандартный Chromium в Ubuntu требует `snapd`, установите его как чистый `.deb`-пакет через официальный PPA-репозиторий:

```bash
# Добавляем репозиторий
sudo add-apt-repository ppa:xtradeb/apps -y
sudo apt update

# Устанавливаем Chromium
sudo apt install chromium -y
```

### 2. Клонирование и установка зависимостей Python
Убедитесь, что у вас активировано виртуальное окружение (`venv`), и установите библиотеки:

```bash
pip install -r requirements.txt --break-system-packages
```

*Содержимое `requirements.txt`:*
```text
selenium==4.25.0
webdriver-manager==4.0.2
pypdf==5.1.0
```

## 📖 Инструкция по использованию

### Шаг 1: Конвертация MHT в PDF
1. Положите ваш файл книги в папку со скриптом и переименуйте его в `book.mht` (или укажите правильный путь в коде `convert.py`).
2. Запустите скрипт конвертации:
   ```bash
   python3 convert.py
   ```
3. Скрипт запустит Chromium в фоновом режиме, прокрутит книгу, выровняет слои и сохранит результат в файл `result_book.pdf`.

### Шаг 2: Ручная или автоматическая обрезка полей
Если на страницах книги остались ненужные пустые поля, шапки сайтов или колонтитулы, их можно обрезать.

#### Вариант А: Автоматически через Python
Запустите скрипт `crop_pdf.py` (настройки отступов в пунктах меняются внутри файла):
```bash
python3 crop_pdf.py
```

#### Вариант Б: Вручную мышкой (Графический интерфейс Linux)
Установите утилиту **Briss**, которая позволяет наложить все страницы друг на друга и обрезать их одним выделением:
```bash
sudo apt install briss -y
```
Запустите программу, откройте `result_book.pdf`, выделите рамкой текстовую область книги и сохраните результат через `Action -> Crop PDF`.

#### Вариант В: Через терминал одной командой
Используйте утилиту `pdfcrop` (значения задаются в пунктах, отрицательные числа отрезают края):
```bash
sudo apt install texlive-extra-utils -y
# Пример: отрезать по ~1.5 см (40 пунктов) сверху и снизу
pdfcrop --margins '0 -40 0 -40' result_book.pdf cropped_book.pdf
```

## 🔧 Возможные проблемы и их решение
* **Пропадают картинки:** Если книга слишком тяжелая и картинки не успевают подгружаться при прокрутке, откройте `convert.py` и увеличьте время ожидания в строке `time.sleep(0.2)` (например, до `0.5` или `1.0`).
* **Текст накладывается:** Убедитесь, что блок кода `js_fix_layers` внутри `convert.py` не содержит сторонних комментариев со знаком `#` — внутри многострочной JS-строки должны использоваться только комментарии вида `//`.
